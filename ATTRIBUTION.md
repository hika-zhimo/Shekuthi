# Attribution and excluded assets

The icons, illustrations and design-reference documents listed below are **not
our work**. To avoid redistributing files whose provenance we cannot fully
confirm, they are **intentionally not tracked in this repository**. The paths
are listed in `.gitignore`; local copies keep development working, but a fresh
clone will not contain them.

Restore any set by downloading from the source below and copying the files back
into the same path. No application code needs to change.

Where a source could not be confirmed, that is stated plainly rather than
guessed at.

## Homepage landscape inspiration — 2026-10-05 (M61.2)

The original Shekuthi illustration `backend/public/img/hill-village-produce.svg`
is inspired by the minimalist landscape theme of
[Dylan Ramjee’s landscape emblem on Vecteezy](https://www.vecteezy.com/vector-art/57397707-minimalist-black-and-white-landscape-emblem-featuring-stylized-trees-rolling-hills-and-mountains-against-a-blank-white-background).

- Reference creator: **Dylan Ramjee**, as listed on Vecteezy.
- Reference listing: **Free License — Attribution Required**, as displayed on
  the source page; this does not make the source artwork part of our licence.
- Use: general inspiration for bold tree silhouettes, layered rolling hills,
  mountain shapes and white negative space. The village, produce basket and
  SVG paths are original project artwork; no source vector/image is copied,
  traced, bundled or redistributed.
- Palette: logo green `#008000`, white `#FFFFFF`, black `#000000` only.
